# Rock Paper Scissors Game 🎮

## 📌 About the Project
This is a simple and interactive Rock Paper Scissors game developed using HTML, CSS, and JavaScript. The player chooses Rock, Paper, or Scissors, and the computer randomly selects one option. The winner is decided based on the game rules.

## 🛠️ Technologies Used
- **HTML** – Structures the webpage.
- **CSS** – Styles the game and aligns the elements.
- **JavaScript** – Implements the game logic and determines the winner.

## 🎯 Game Rules
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both the player and computer choose the same option, it is a draw.

## 🚀 How to Run the Game
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Choose Rock, Paper, or Scissors to start playing.
